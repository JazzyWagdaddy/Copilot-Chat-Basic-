# Microsoft Copilot Chat Basics — Hands-On Lab Guide

**Audience:** Beginners with little or no prior AI chat experience

**Time:** ~20 minutes

**You'll need:** A web browser and access to copilot.microsoft.com (or the Copilot app/pane your organization uses)

***Remember GCSE***

**G**oal — what do you want it to do?

**C**ontext — who's it for / why?

**S**ource — what info should it use?

**E**xpectations — format, length, tone?


---

## Before You Start

1. Open a browser and go to **copilot.microsoft.com**.
2. Sign in with your Microsoft account (work/school account preferred if available).
3. You should see an empty chat window with a text box at the bottom — that's where you'll type.

> **Tip:** Don't paste any real sensitive work data during this lab (names, client info, financial details). Use placeholder or made-up details instead.

---

## Exercise — Vague Prompt vs. GCSE Prompt (5 min)

**Goal:** See the difference a well-structured prompt makes.

**Step 1.** Type this vague prompt exactly as written and press enter:

```
Write an email about the project.
```

Read the response. Notice how generic it is — it has to guess at almost everything.

**Step 2.** Now try a GCSE version. Replace the *bracketed details* with something realistic to your role:

```
I need to send a status update email to my manager about [project name].
We're on track but [one task] is running a few days behind because of
[reason]. Write a short, professional email (under 150 words) that
explains the delay and proposes a solution.
```

**Step 3.** Compare the two responses and make note of 1–2 differences.

## Exercise — Summarize in Different Formats (5 min)

**Goal:** Practice the "Source" and "Expectations" parts of GCSE.

**Step 1.** Copy and paste the paragraph below into Copilot Chat:

```
Hybrid work has become the norm for many organizations, but it introduces challenges
around collaboration, scheduling, and maintaining team culture.
Companies are experimenting with core in-office days, asynchronous communication tools,
and new meeting norms to balance flexibility with connection.
Early data suggests that teams with clear communication guidelines report higher satisfaction,
while teams without structure often report feelings of isolation despite having more flexibility.
```

**Step 2.** Ask for three different summary formats, one at a time:

```
Summarize this in one sentence.
```

```
Summarize this as 3 bullet points for a slide.
```

```
Summarize this for a 10-year-old.
```

## Exercise — Brainstorm and Refine (5 min)

**Goal:** Practice iterating instead of starting over.

**Step 1.** Start a brainstorm:

```
I'm planning a team lunch to celebrate hitting a project milestone.
Suggest 5 fun theme ideas.
```

**Step 2.** Pick one idea from the list and refine it with a follow-up — don't start a new prompt, just reply in the same chat:

```
I like idea #2 — can you build a simple plan around it, including
a rough timeline and a budget estimate for 10 people?
```

**Step 3.** Try one more refinement of your choice (e.g., "make it cheaper," "make it virtual-friendly," "add a fun activity").

## Task 2: Calendar check plus meeting follow-up draft

### Goal
Find an upcoming meeting and prepare a follow-up message.

### Prompt flow
1. When is my next 1:1 meeting with *[person]*?
2. Show recent related emails.
3. Draft a short email confirming the meeting.
4. Rewrite the email to be professional and under 120 words.

## Exercise -  Upload a file and turn it into an executive-ready update

### Goal
Use an uploaded file to create a leadership summary.

### Prompt flow
1. Upload the file.
2. Summarize in 5 bullet points.
3. Identify risks, decisions, and actions.
4. Draft a short leadership email.
